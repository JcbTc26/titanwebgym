# Titan Fitness Club

Proyecto web de un gimnasio ficticio desarrollado con HTML, CSS y JavaScript.

La página principal muestra los servicios, las instalaciones, testimonios y un formulario de contacto. También incluye un planificador de entrenamiento en una página independiente.

El usuario puede introducir datos como edad, peso, altura, nivel de experiencia, objetivo, días disponibles y lugar de entrenamiento. Con esa información, la aplicación genera una rutina orientativa y permite guardarla en el navegador.

## Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* Flexbox
* CSS Grid
* LocalStorage
* Diseño responsive

## Archivos principales

```text
index.html
planificador.html
css/
js/
img/
fonts/
```

## Cómo abrir el proyecto

Se recomienda usar Live Server desde Visual Studio Code y abrir `index.html`.

## Aviso

Los planes generados son orientativos y no sustituyen la valoración de un profesional sanitario o del ejercicio.
